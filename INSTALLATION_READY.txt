## 🚀 快速开始

### 方式1: 一键安装（推荐）

```bash
cd /path/to/deploy_newmind
./install.sh
```

安装脚本特点:
  • 半自动模式（每步骤确认）
  • 支持断点续传
  • 详细进度显示
  • 自动验证和报告

### 方式2: 后续启动

首次安装后，使用:
```bash
bash scripts/start_all.sh
```

  1. 系统预检查              (1分钟)
