 🚀 快速安装指南
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 准备工作
   • 将整个 deploy_newmind 目录从移动硬盘复制到Mac本地
   • 确保有足够的硬盘空间

2. 开始安装
   • 打开终端 (Terminal)
   • cd 到 deploy_newmind 目录
   • 运行: ./install.sh

3. 安装过程
   • 安装程序会逐步提示每个安装步骤
   • 确认后会自动安装所有组件
   • 整个过程需要 10-20 分钟

4. 启动平台
   • 安装完成后运行: ./start_all.sh
   • 或者让安装程序自动启动

5. 访问Dashboard
   • 打开浏览器访问: http://localhost:8000
   • 可以管理所有服务和MCP实例

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题: 安装中断
解决: 重新运行 ./install.sh，会自动恢复或重新开始

问题: 端口被占用
解决: 停止占用端口的程序，或修改 docker-compose.yml

问题: Docker启动失败
解决: 确保 Docker Desktop 已正确安装并运行

问题: 模型无法加载
解决: 检查 ~/.lmstudio/models/ 目录权限
