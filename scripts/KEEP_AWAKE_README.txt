===============================================================================
                     Mac 系统保活脚本使用说明
                   防止远程连接（ToDesk）断开
===============================================================================

📦 包含的脚本文件：

1. setup_keep_awake.sh          - 主安装脚本（配置系统保持唤醒）
2. uninstall_keep_awake.sh      - 卸载脚本（恢复原始设置）
3. check_keep_awake_status.sh   - 状态检查脚本（查看当前配置）

===============================================================================

🚀 快速开始：

第一步：安装保活服务
--------------------
在终端中运行：

    cd /Users/ablatazmat/Downloads/deploy_newmind/scripts
    sudo ./setup_keep_awake.sh

脚本会自动完成以下操作：
  ✓ 备份当前电源设置
  ✓ 配置系统电源管理（禁用睡眠）
  ✓ 创建 LaunchDaemon 保活服务
  ✓ 启动保活服务
  ✓ 验证配置是否成功


第二步：检查状态（可选）
--------------------
安装完成后，可以运行：

    ./check_keep_awake_status.sh

这会显示：
  • LaunchDaemon 服务状态
  • Caffeinate 进程状态
  • 电源管理设置
  • 日志文件信息
  • 系统运行时间
  • 网络状态
  • 配置建议

===============================================================================

🔍 功能说明：

配置的电源管理设置：
--------------------
• 系统睡眠：禁用（不会进入睡眠）
• 显示器睡眠：禁用（拔掉显示器也不睡眠）
• 硬盘睡眠：禁用
• 网络唤醒：启用
• TCP 保活：启用
• 待机模式：禁用

LaunchDaemon 服务：
--------------------
• 服务名称：com.newmind.keepawake
• 开机自启：是
• 持续运行：是（如果进程退出会自动重启）
• 运行账户：root（系统级别）
• 使用工具：caffeinate（Apple 官方工具）

文件位置：
--------------------
• 服务配置：/Library/LaunchDaemons/com.newmind.keepawake.plist
• 保活脚本：/usr/local/bin/newmind_keepawake.sh
• 主日志：/var/log/newmind_keepawake.log
• 标准输出：/var/log/newmind_keepawake_stdout.log
• 标准错误：/var/log/newmind_keepawake_stderr.log
• 备份目录：/usr/local/var/newmind_backup/

📊 验证方法：

方法1：使用状态检查脚本
--------------------
    ./check_keep_awake_status.sh

方法2：手动检查服务
--------------------
    # 查看 LaunchDaemon 服务
    sudo launchctl list | grep keepawake

    # 查看 caffeinate 进程
    ps aux | grep caffeinate

    # 查看电源设置
    pmset -g

方法3：实际测试
--------------------
1. 拔掉显示器
2. 等待 5-10 分钟
3. 尝试通过 ToDesk 连接
4. 应该能正常连接

===============================================================================

🔧 故障排除：

问题1：ToDesk 仍然断开
--------------------
解决方案：
1. 检查 ToDesk 设置中是否启用了"开机自动启动"
2. 确认 ToDesk 中启用了"后台运行"
3. 运行状态检查脚本：./check_keep_awake_status.sh
4. 重启系统后再次测试

问题2：服务未启动
--------------------
解决方案：
    # 查看日志
    sudo tail -50 /var/log/newmind_keepawake.log
    
    # 手动启动服务
    sudo launchctl load /Library/LaunchDaemons/com.newmind.keepawake.plist

问题3：系统仍然进入睡眠
--------------------
解决方案：
1. 检查电源设置：pmset -g
2. 重新运行安装脚本：sudo ./setup_keep_awake.sh
3. 检查是否有第三方电源管理软件冲突

问题4：查看详细日志
--------------------
    # 主日志
    sudo tail -f /var/log/newmind_keepawake.log
    
    # 错误日志
    sudo tail -f /var/log/newmind_keepawake_stderr.log
    
    # 系统日志
    log show --predicate 'process == "caffeinate"' --last 1h

🗑️ 卸载方法：

如需恢复原始设置：
--------------------
    cd /Users/ablatazmat/Downloads/deploy_newmind/scripts
    sudo ./uninstall_keep_awake.sh

卸载脚本会：
  • 停止并移除 LaunchDaemon 服务
  • 终止 caffeinate 进程
  • 删除服务文件
  • 恢复默认电源管理设置（可选）
  • 清理日志文件（可选）

===============================================================================

⚙️ 自定义配置：

如果你想自定义电源设置：
--------------------
1. 先运行安装脚本创建服务
2. 然后在系统设置中调整：
   - 系统设置 > 锁定屏幕 > 关闭显示器前的闲置时间
   - 系统设置 > 电池 > 电源适配器
   
3. 或使用 pmset 命令：
   sudo pmset -a displaysleep 30  # 设置显示器 30 分钟后睡眠
   sudo pmset -a sleep 0          # 系统永不睡眠

===============================================================================

💡 重要提示：

1. 电池使用：
   - 如果使用笔记本电脑，这会增加电池消耗
   - 建议保持连接电源适配器
   
2. 安全性：
   - 保持系统不睡眠可能有安全风险
   - 确保设置了锁屏密码
   - 考虑使用防火墙限制远程访问

3. 系统更新：
   - macOS 系统更新后，设置通常会保留
   - 但建议更新后运行状态检查脚本验证

4. 性能影响：
   - caffeinate 本身资源占用极小
   - 但系统不睡眠会持续运行所有后台进程
