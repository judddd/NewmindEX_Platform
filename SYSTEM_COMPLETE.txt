## 📦 打包为USB安装盘

### 方法1: 直接复制
```bash
# 复制到USB
cp -R /Users/ablatazmat/Downloads/deploy_newmind /Volumes/YOUR_USB/

# 在新Mac上使用
cd /Volumes/YOUR_USB/deploy_newmind
./install.sh
```

### 方法2: 压缩打包
```bash
cd /Users/ablatazmat/Downloads
tar -czf newmind-offline-v1.0.tar.gz deploy_newmind/
# 复制到USB，解压后使用
```

### 方法3: 创建DMG
```bash
hdiutil create -volname "NewMind Installer" \
  -srcfolder deploy_newmind \
  -ov -format UDZO \
  newmind-installer-v1.0.dmg
```
